# Time-Series Additive Models

This project is being rebuilt as a professional, reproducible research codebase for transparent additive time-series modelling.

## Objectives

- explicit statistical model components;
- reproducible experiments;
- typed and tested Python code;
- separation between maintained code and historical notebooks;
- diagnostics and rolling-origin evaluation;
- documented assumptions and data provenance.

The original notebook is retained as historical material only. Maintained modelling code lives under `src/time_series_additive_models/`.
